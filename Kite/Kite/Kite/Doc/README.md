# Kite Docs

**This is the main docs folder for the iOS app.**

Path: `IOS/Kite/Kite/Docs`

Put feature plans, architecture notes, and to-dos here (e.g. `feature_item.md`).

Do not put docs under `Kite/Kite/Kite/Docs` or `IOS/Doc` — those locations get confusing / lost. Keep everything in this folder.
